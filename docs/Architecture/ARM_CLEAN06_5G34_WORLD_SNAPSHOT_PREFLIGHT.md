# ARM-CLEAN06.5G.34 — Préflight canonique des snapshots monde

Parent a72bc7fe09b3b228332a1ae737a436d96a5d1fa4. Validation avant la première mutation : ItemSystem configuré pour tout item, ItemId et niveau physique exacts, quantité positive et limitée par MaxStack, GUID unique dans un niveau, cohérence clé et propriétaire du réceptacle ; projectile enchâssé = une munition canonique associée à un monstre. Les anciens pointeurs ne sont jamais consultés. Continue vérifie tous les snapshots, incluant les niveaux non actifs et files PIT, avant restauration du groupe et reconstruction du niveau ; la réhydratation du groupe a lieu avant RebuildLevel. Le déplacement inter-niveaux refuse un snapshot destination invalide avant de quitter la source. L'application directe refuse avant toute mutation, y compris la file d'un niveau non visité. 

Le nouveau test réel avec une GameInstance configurée prouve la non-mutation de l'acteur/transform sur un niveau physique invalide, le refus d'un ID inconnu, d'une duplication sol/file PIT, d'une quantité invalide et d'un mauvais owner de réceptacle. La validation ne prétend pas encore couvrir une panne de spawn UE ni les duplications entre niveaux : tests et contrôle de transaction physique restent distincts. Les fixtures Automation historiques volontairement sans GameInstance gardent temporairement leur parcours direct, jamais en Shipping. Aucun format SaveGame, asset ni texte joueur nouveau.
