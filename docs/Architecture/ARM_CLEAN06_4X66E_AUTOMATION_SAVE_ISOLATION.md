## Isolation et régression
ValidateUE démarre chaque processus Automation avec un UserDir unique sous son rapport privé et un marqueur explicite. Le module de développement refuse le démarrage si FPaths::ProjectSavedDir ne désigne pas le Saved de cette racine indépendante ; le script exige le marqueur de preuve, compare l'inventaire SHA256 live avant/après et refuse tout .sav résiduel dans le répertoire isolé (sans suppression de preuves). Cette protection s'applique à tous les tests lancés par le runner, même producteurs indirects. Les huit fichiers identifiés comme producteurs de slots disque (MON135, MON188, MON1891, SHIELD025, SAVEFIX2, MON9, ARMEMENT01132 et ARMEMENTLOT0216) exigent aussi le contexte isolé avant leurs tests disque ; un lancement de ces tests dans un éditeur normal est refusé. Le jeu et le PIE manuel ne changent pas. Les tests non concernés restent inchangés. MON135 supprime et vérifie ses deux slots exacts avec l'autorité de nommage FGridCombatSavePolicy ; MON188 contrôle le résultat de son destructeur et la présence physique du fichier dans le Saved isolé. Le test AutomationSaveIsolation couvre le chemin réel et le rejet des chemins non conformes. Le runner conserve les preuves privées en cas d'échec. Les checkpoints joueur, y compris GrimrockParty_AutoCombat, ne font l'objet d'aucune suppression.
