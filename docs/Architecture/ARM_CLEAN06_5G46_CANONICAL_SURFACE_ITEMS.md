# ARM-CLEAN06.5G.46 — Consommables de surface exclusivement canoniques

Parent 93abacb6de60abf8624b894b812a7de0389ee160. Publication après les deux statuts SUCCESS.

Suppression effective de la dépendance à UGridItemDefinitionAsset dans le lecteur d’exploration 5D. Les deux identités approuvées huile/catalyseur résolvent strictement leur action QuickItem détaillée N0, capacité et mesh dans ItemSystem. Le mesh après consommation est lu dans le registre, sans exiger une instance restante. Les raccourcis vides peuvent encore afficher l’action désactivée ; toute exécution exige une vraie pile. Registre absent, identité inconnue et quantité/niveau invalides échouent explicitement. Aucun changement de règle de surface, de coût, de ciblage, d’événement ou de texte joueur.

Les quatre tests de pipeline MON12 (ARMEMENT01.17.1.4, 17.1.7, 17.2B et 17.3B) utilisent le vrai registre et ne chargent ni n’enregistrent l’ancien consommable. L’épée synthétique sans rapport avec ces scénarios est retirée de leur fixture ; tous les contrôles de coût, consommation, ciblage, réactions, projectile, splash et événements restent en place. 5D renforce les refus, le mesh après consommation et l’identité exacte. Les autres lecteurs QuickItem génériques et les anciennes fixtures de kits restent à migrer. Aucun asset, sauvegarde ou schéma modifié ; le PIE alchimie et Shipping restent à confirmer.
