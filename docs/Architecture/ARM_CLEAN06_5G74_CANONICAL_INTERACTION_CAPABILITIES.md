# ARM-CLEAN06.5G.74 — Autorité canonique des capacités d'interaction

Parent 15e89ba3bd5be245659a381b3d75d2a493dcca70. Publication après double validation Windows du parent.

Le lecteur partagé par menus, inventaire, tooltips et hotbar refuse les identités inconnues au lieu de leur attribuer les capacités de l'ancien DA_Item ou le texte d'une instance non reconnue. Le texte narratif et ses overrides restent supportés pour les instances canoniques valides. Le chemin historique reste limité aux fixtures Automation sans registre. Aucun changement de texte joueur, WBP, asset, schéma ou sauvegarde.

Le test 3AW couvre la définition Book historique, l'override d'une identité inconnue, le menu réel Read/Consume, la potion historique contradictoire et la fixture isolée positive. Les tests existants de lecture d'une instance ARM valide et de raccourcis canoniques restent inchangés. Les autres chemins d'exécution des anciennes actions de test seront audités séparément.
