# GrimrockPrototype — Vue d’ensemble

GrimrockPrototype met en jeu un groupe explorant un donjon sur grille en vue subjective. Le prototype réunit le déplacement, les objets et mécanismes, les rencontres et combats, la progression RPG et la reprise de partie. Les niveaux sont édités dans Unreal avec le Grid Editor. Le projet conserve des outils distincts pour le jeu, l’édition, les scripts Lua et la validation Windows.

Le [résumé des systèmes](../Architecture/PROJECT_SYNTHESIS.md) décrit les responsabilités et niveaux de validation actuels. Le [modèle relationnel](../Architecture/DataModel.md) couvre les objets, leur possession et la persistance v27. Les gammes d’équipement non matérialisées restent des propositions.

La [roadmap](PROJECT_COMPLETION_ROADMAP.md) distingue la recette générale, les fonctionnalités livrées, les travaux suspendus et les décisions produit encore attendues. Les [preuves de consolidation](../Technical/Consolidation.md) fixent les références techniques.
