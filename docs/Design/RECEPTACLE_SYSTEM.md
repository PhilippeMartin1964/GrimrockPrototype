# Receptacle System

## 1. Objet

Ce document définit le système de **réceptacles** de GrimrockPrototype.

Un réceptacle est un objet du niveau capable de recevoir, contenir, exposer, stocker ou restituer un ou plusieurs items selon des règles de capacité, de compatibilité, de visibilité, d'interaction et d'événements.

Le but est de stabiliser le concept avant de corriger ou refondre le code runtime.
