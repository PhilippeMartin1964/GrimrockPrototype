# UI-RPG — Visual Asset Index

Ce dossier est le point d'entrée des visuels de conception et de documentation du chantier UI-RPG.

## Convention de nommage

Les fichiers validés doivent utiliser des noms stables, sans espace :

```text
UI_RPG01_TalentTree_Wireframe.png
UI_RPG01_DataContract.png
UI_RPG01_RuntimeProjection.png
UI_RPG01_ProductionValidation.png

UI_RPG02_Class_Warrior.png
UI_RPG02_Class_Rogue.png
UI_RPG02_Class_Ranger.png
UI_RPG02_Class_Mage.png
UI_RPG02_Class_Priest.png
UI_RPG02_Class_Alchemist.png

UI_RPG02_Branch_<Class>_<Branch>.png
UI_RPG02_NodeStates.png
```

## Statut

À la clôture de UI-RPG01, les directions graphiques des quatre planches UI-RPG01 sont validées dans le flux de conception, mais les fichiers raster ne sont pas encore versionnés ici.

Ils ne doivent pas être reconstruits à partir d'une description approximative. Lorsqu'un export final validé est disponible, il est ajouté dans ce dossier par un commit documentaire/asset dédié.
